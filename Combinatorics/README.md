# 巴斯卡三角形與組合數計算筆記

## 1. 什麼是巴斯卡三角形？
巴斯卡三角形（Pascal's Triangle）是一個幾何排列的數字三角形，其頂端是數字 `1`，往下每一行的兩端都是 `1`，而內部每一個數字都等於**它正上方偏左與正上方偏右兩個數字的和**。

Row 0:         1
Row 1:       1   1
Row 2:     1   2   1
Row 3:   1   3   3   1
Row 4: 1   4   6   4   1

在數學上，巴斯卡三角形的第 $n$ 行、第 $k$ 個數字，剛好就是組合數 $\binom{n}{k}$（即從 $n$ 個物品中選出 $k$ 個的方法數）。

---

## 2. 核心數學原理：巴斯卡恆等式
組合數之所以能用巴斯卡三角形來遞迴計算，是因為它滿足以下性質：

$$\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$$

### 組合意義：
假設要從 $n$ 個物品中選出 $k$ 個，我們看其中一個特定的物品：
1. **如果一定要選這個物品**：必須從剩下的 $n-1$ 個物品中選出 $k-1$ 個，即 $\binom{n-1}{k-1}$。
2. **如果絕對不選這個物品**：必須從剩下的 $n-1$ 個物品中選出 $k$ 個，即 $\binom{n-1}{k}$。

兩者相加即為總選法。這剛好對應到巴斯卡三角形中「上方兩數相加等於下方數值」的規則。

---

## 3. 為什麼在程式中推薦使用巴斯卡三角形來算組合數？

相比於直接使用階乘公式 $\frac{n!}{k!(n-k)!}$，透過巴斯卡三角形（動態規劃）計算組合數有兩大優勢：

1. **避免數值溢位與除法取模問題**：
   階乘成長極快，容易超出 `long long` 範圍。若用巴斯卡三角形，每一步相加都可以直接 `% mod`，確保數值安全。
2. **避開模反元素（Modular Inverse）**：
   在模數運算下，階乘公式的分母需要做除法，程式實作較複雜；而巴斯卡三角形全程僅需**加法**，非常直覺且高效。

---

## 4. C++ 實作範例

利用二維陣列（或動態規劃表格）預先建構出巴斯卡三角形：

```cpp
#include <vector>

const int MOD = 1e9 + 7;

// 預先產生至多 n 層的巴斯卡三角形
std::vector<std::vector<long long>> generatePascalTriangle(int n) {
    std::vector<std::vector<long long>> table(n + 1, std::vector<long long>(n + 1, 1));
    
    for (int i = 2; i <= n; ++i) {
        for (int j = 1; j < i; ++j) {
            table[i][j] = (table[i - 1][j - 1] + table[i - 1][j]) % MOD;
        }
    }
    
    return table;
}
```
+ 時間複雜度： $O(N^2)$，只需在開頭預先計算一次。
+ 空間複雜度： $O(N^2)$，儲存組合數表格。
